# Frontend SAGE INDEX

Interface React 19 construite avec Vite et TypeScript.

## Développement

```powershell
npm install
npm start
```

L’application est disponible sur `http://localhost:4200` et transmet les
requêtes `/api` au backend local sur `http://localhost:18081`.

## Production

```powershell
npm run build
```

Le résultat de production est généré dans `dist/`.
